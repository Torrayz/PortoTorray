# Skills & Tools brand assets

These SVG files are sourced from the [Devicon](https://github.com/devicons/devicon) project, preserving the original brand colours and vector geometry. Each logo remains a trademark or logo of its respective owner. SVG files are committed locally so no third-party CDN request is needed to render portfolio skills.

The name of each SVG maps to the corresponding item in `components/TechLogoGrid.tsx`.
